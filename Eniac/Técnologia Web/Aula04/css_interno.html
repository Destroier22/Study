CSS Interno

CSS significa Folha de Estilo em Cascata e descreve como os elementos HTML devem ser exibidos na tela. 1rem é o tamanho padrão do dispositivo 1pt = 1.333px = 0.0625rem 1 rem = 16pt = 21,328px

O CSS tem Syntaxe também, exemplo
seletor{ propriedade: valor; propriedade: valor; } seletor = Quem eu quero mudar
